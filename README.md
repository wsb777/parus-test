# Тестовое задание

## Описание
Сервис для публикации и проверки обновлений с проверкой целостности файлов через хеш-суммы.

## Установка
1. `git clone https://github.com/wsb777/parus-test.git`
2. `git checkout dev`
3. Создайте `.env` и заполните по образцу `.env.example`
4. Запустите через `docker compose up -d`

Проект запустится на 443-м порту, если он свободен, но будет требовать подтвердить переход на страницу

## Использование
1. Все маршруты защищены аутентификацией, кроме `/auth` — через него выполняется авторизация и выдаётся токен
2. На маршрутах `/admin` установлен middleware для проверки прав администратора
3. Документация Swagger доступна по адресу `/swagger`

## Пояснения
1. CORS настроен глобально, поскольку сервис предполагает взаимодействие с клиентскими приложениями, а не с конкретным сайтом — регистрировать все возможные IP нецелесообразно
2. Скачивание файла происходит не по прямой ссылке на директорию, а через бинарные данные в теле ответа с хеш-суммой в заголовке `Digest` — это сделано во избежание атаки типа path traversal
